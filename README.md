# LabDuty · 实验室值日与协同管理平台

一个**单文件、零构建、零依赖**的静态 Web 应用，用于实验室多人编制的**值日轮转**与**成员职责管理**。
直接双击 `index.html` 即可运行，也可以部署到任意静态托管（GitHub Pages / Cloudflare Pages / 内网服务器）。

🔗 **在线访问**：<https://cry-aml.github.io/lab-duty-roster/>

## 功能

### 人员轮转中枢
- **11 人 · 14 日（2 周）轮换**：规则为「每 2 周全员整体下移一格，末位补首位」，岗位职责内容不变、人员循环流动。
- **周期推演**：上一周期 / 下一周期 / 任意日期跳转；`Day 1` 基准起始日可在线配置（默认 10 月第 3 周周一）。
- **轮转闭环**：任一成员在 11 期内恰好覆盖全部 11 个岗位（11 期为一整轮闭环）。

### 成员 Duty 专页
- **固定责任人分工**：逐字引用规约表「责任内容」栏，不作补写；原文以括号枚举的成员（如细胞耗材、公共 Buffer）额外按项列出。
- **值日专责规程（随岗位轮转）**：逐字引用规约表「区域打扫内容」清单（细胞房 6 项 / 实验室 4 项 / 休息室 2 项），并标注来源；规约表未单列清单的岗位如实显示「未定义」，不补写内容。
- **11 期完整轮转时间轴**：推演该成员未来 11 个周期的完整轨迹。

### 轮值计划表
- **本周期岗位视图**：11 个岗位卡片格网，标注当值人、频次、协同成员、下期接替人。
- **轮换总览大表**：岗位 × 当值 × 接替 × 频次 × 专责焦点。

### 其他
- **A4 打印张贴表**：专用打印版式，自动隐藏交互控件。
- 执行规约：清洁时间窗口、枪头插盒指标、库存核查频次。

## 隐私说明（重要）

本仓库为**公开**仓库。为保护成员隐私，页面中的成员一律以**「姓氏首字母 + 名字首字母」的拼音缩写**表示（例如 `H.W.Y`），
成员 ID 使用中性代号 `M01`–`M11`，**仓库内不含任何真实姓名**。

> 请注意：拼音首字母缩写属于**假名化（pseudonymization）**而非匿名化——它保留了姓氏与名字的首字母。
> 如果你要在**真实团队**中使用本工具，建议在受控（私有）环境中自行替换为真实姓名。

### 如何替换为真实姓名
编辑 `index.html` 中的两处数据（成员 ID 保持不变即可，全站渲染与轮转算法自动生效）：

1. `BASE_MEMBERS` 数组中每个成员的 `name` 字段；
2. `MEMBERS` 对象中对应成员的 `name` 字段。

## 技术要点

- **单文件**：纯 HTML + CSS + 原生 JavaScript，无框架、无 CDN、无外部字体（完全自包含，可离线运行）。
- **设计令牌**：Apple HIG 风格令牌体系（背景 / 前景 / 边框 / 强调色 / 圆角 / 阴影 / 动效时长与缓动），集中定义于 `:root`。
- **响应式**：360 / 390 / 430 / 600 / 820 / 1024 / 1366 / 1440 / 1920 共 9 档视口实测**无横向溢出**。
- **无障碍**：语义化标题层级、真实 `button`/`select`/`input` 控件、可见聚焦态、模态 `role="dialog"` + `aria-modal`、Toast `aria-live`。
- **数据持久化**：仅 `Day 1` 基准日期存于 `localStorage`；在 `file://` 或隐私模式下自动降级为内存态。
